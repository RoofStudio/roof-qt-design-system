# roof-qt-design-system

A small Python design system for building desktop tools at Roof Studio with
[PySide6](https://doc.qt.io/qtforpython-6/) (Qt for Python). It packages a set of
pre-styled widgets, window/page layouts, a minimal page router, a dark Qt
stylesheet and an SVG icon set, so internal pipeline tools share the same look
and structure.

The bundled demo (`main.py`) opens an empty window titled
"Roof Environment Installer", and the `ComputerList` widget is built for
listing machines with their status and user, which reflects the kind of
internal tooling this library was written for.

## Features

- **`MainWindow`** – a `QMainWindow` with a `QStackedWidget` as its central
  widget, optional window icon, minimum size, and the design-system
  stylesheet applied automatically. Pages are registered as routes.
- **`Page`** – a base page widget with a centered `Header` at the top.
- **Components**
  - `Header` – a centered title bar.
  - `LineEdit` – a labeled text input (label above or beside the field), with
    `text()` and `connect(action)` helpers (`action(text=...)` is called when
    Return is pressed).
  - `ContentComponent` – a padded vertical container.
  - `ComputerList` – a 3-column table (default headers: "Computer Name",
    "Status", "User") filled from a list of dicts with `name`, `status` and
    optional `username` keys.
- **Router** – `Route` / `new_route(name, component)` to describe the pages
  shown by `MainWindow`.
- **Styles** – dark theme Qt stylesheets (`styles/*.css`), concatenated and
  returned by `get_stylesheet()`.
- **Icons** – roughly 290 SVG icons in `RoofDesignSystem/icons/`;
  `get_icons()` returns a `{name: absolute_path}` dict keyed by file name
  without extension.

## Tech stack

- Python (the Pipfile targets Python 3.11)
- PySide6 6.5
- Tooling: [pipenv](https://pipenv.pypa.io/), [invoke](https://www.pyinvoke.org/)
  for tasks, [black](https://black.readthedocs.io/) for formatting

```

    ├── icons/               # SVG icons + get_icons()
    └── templates/           # (empty package)
```

## Installation

### For development

```bash
git clone https://github.com/RoofStudio/roof-qt-design-system.git
cd roof-qt-design-system
pipenv install --dev
pipenv shell
```

Or with pip:

```bash
pip install -r requirements.txt
```

### As a dependency in another project

Releases are tagged in Git (e.g. `v0.3.3`), so the package can be installed
from the repository:

```bash
pip install "git+https://github.com/RoofStudio/roof-qt-design-system.git@v0.3.3"
```

> **Note:** `setup.py` does not declare `package_data` / `include_package_data`,
> so the `.css` and `.svg` files may not be copied by a regular (non-editable)
> install. If styles or icons are missing, install in editable mode
> (`pip install -e <path>`) or vendor the repository.

## Usage

```python
import sys

from PySide6.QtWidgets import QApplication

from RoofDesignSystem.layouts.mainWindow import MainWindow
from RoofDesignSystem.layouts.page import Page
from RoofDesignSystem.components.lineEdit import LineEdit
from RoofDesignSystem.router import new_route


class LoginPage(Page):
    def __init__(self):
        super().__init__(title="Login")
        username = LineEdit(label_text="Username")
        username.connect(lambda text: self.next_page(1))
        self.layout.addWidget(username)


class HomePage(Page):
    def __init__(self):
        super().__init__(title="Home")


app = QApplication(sys.argv)
window = MainWindow(
    width=500,
    height=500,
    title="My Tool",
    routes=[
        new_route("login", LoginPage()),
        new_route("home", HomePage()),
    ],
)
window.show()
sys.exit(app.exec())
```

How routing works: `MainWindow.setup_routes()` adds each route's component to
the stacked widget in order and injects a `next_page(index)` callable into it,
so a page can switch to another page by its index. `MainWindow.set_page(index)`
and `MainWindow.get_page(name)` (looks up a child widget by object name) are
also available.

Icons:

```python
from PySide6.QtGui import QIcon
from RoofDesignSystem.icons import get_icons

icons = get_icons()
icon = QIcon(icons["academic-cap"])
```

Styles are applied automatically by `MainWindow`; to use them elsewhere call
`RoofDesignSystem.styles.get_stylesheet()` and pass the result to
`setStyleSheet()`. Widgets are targeted by class name in the CSS (e.g.
`Header`, `LineEdit`, `MainWindow`).

## Development tasks

Defined in `tasks.py` (run with `invoke <task>`):

| Task | What it does |
| --- | --- |
| `invoke start` | Runs `lint`, then `python main.py` (demo window) |
| `invoke lint` | Formats the code with `pipenv run black .` |
| `invoke test` | Runs `lint`, then `python -m unittest` (no tests exist yet) |
| `invoke clean` | Deletes `*.pyc` files |
| `invoke lock` | Regenerates `requirements.txt` from the pipenv environment |
| `invoke release --fix-type <bug\|low\|high>` | Bumps the version in `setup.py` (patch / minor / major), commits "Release … Fix", tags `v<version>` and pushes commits and tags |

## Notes

- `setup.py` classifiers list Python 2.7, but some components use the
  zero-argument `super()` form and the library depends on PySide6, so in
  practice Python 3 is required.
- `get_icons()` lists every file in the icons folder, so the returned dict
  also contains an `__init__` entry.
